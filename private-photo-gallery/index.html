使用提示

建议使用 fine-grained token，只授权 photo-vault，权限只开 Contents: Read and write。
本页面不会生成公开 raw 链接，预览图是 GitHub API 授权读取后在浏览器生成的临时地址。
如果以后照片量很大，再考虑迁移到对象存储或 Immich；当前这个版本适合旅行和巡礼照片库。
