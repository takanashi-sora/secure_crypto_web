上传说明

上传页只处理图片上传，让照片库页面保持干净。上传完成后会自动刷新照片库。

Token 需要 Contents: Read and write 权限。
上传文件会自动加时间戳，避免和旧照片重名。
GitHub 适合轻量照片库，不适合无限量原图网盘。

连接设置

这里集中放 GitHub Token 与私有仓库参数。保存后只写入本机浏览器 localStorage，不会提交进仓库。

安全提醒

建议使用 fine-grained token，只授权 photo-vault 一个仓库。
只开 Contents: Read and write，其他权限保持 No access。
不要在公共电脑输入 Token，也不要把 Token 发给任何人。
